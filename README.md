# QuickDesk — Smart Helpdesk & Ticket Management System

QuickDesk is a full-stack helpdesk and ticket management platform built with Django,
designed to simulate a real-world customer support system. Customers can raise support
tickets, agents can pick up and resolve them through a defined workflow (Open → In
Progress → Resolved → Closed), and admins manage users, categories, and view team-wide
analytics.

The project also includes a REST API (Django REST Framework) with JWT authentication,
asynchronous email notifications via Celery and Redis, an analytics dashboard built with
Chart.js, and a fully Dockerized setup.
